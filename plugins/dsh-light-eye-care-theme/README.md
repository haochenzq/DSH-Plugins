# 浅色护眼主题

为 DeepSeek Harness **现有界面**提供暖浅底、浅鼠尾草绿与柔和蓝；保留原有会话、侧栏、输入框、功能和布局。没有示例工作流、模拟数据、背景动画或远程依赖。正文、辅助文字、交互状态和主要按钮选用更深的前景或背景色来保护可读性；浅鼠尾草色并不直接承载白色小字。图标为本包原创 SVG。

## 兼容与启用

适配 DSH `0.2.2-rc.3` 至 `0.2.x`，升级 DSH 后应重新核对主题 token 及效果。先停用其他会覆盖主题的插件（可保留安装），在 **插件** 中添加本目录并启用；或由有权限的操作者用 `plugin_manager` 的 `install_bundle` 指向此目录。然后在 **设置 → 通用 → 外观** 中由用户显式选择 DSH 内置的**浅色**；该操作是用户主动修改 DSH 外观偏好，而非插件修改。默认 `config: {}`，无需插件设置。插件仅添加可卸载的 token 覆盖，不读取或写入外观偏好、其他个人配置，也无网络请求和模型调用。

原生控件仍由 DSH 渲染，字号、排版、语言和数据由 DSH 原设置和功能决定。按钮、链接的颜色等变化有 140ms 的轻微过渡，仅在系统允许动效时启用；系统选择减少动态时不添加这些过渡。此插件不消除其他插件或 DSH 自带的动效。

**外观切换和停用：**插件只在 DSH 当前解析为浅色时应用配色和轻微过渡；切换为深色，或选择跟随系统且系统处于深色时，会自动撤销本插件覆盖层和过渡。本插件不会切换或强制更改用户所选外观。停用或卸载后，覆盖层及注入的交互样式被撤销，当前内置外观偏好不变；若需要恢复手动选择浅色之前的外观，请在设置中自行切回。其他主题可能同时覆盖相同 token，不保证共存时的外观，建议一次只启用一个外观主题。

## 校验和排查

在源码目录运行 `node --check lib/index.js`、`node --check lib/client.js`、`node test.mjs`。测试核对设计色板映射、必要资源、浅色方案覆盖层及深色撤销、模拟异步主题变化和卸载清理，以及若干关键色对的 WCAG 对比度；不能替代安装后的真实界面检查。

安装后打开实际会话、插件页和设置页，检查侧栏、正文、代码、链接、输入框、弹层及焦点是否可读；用系统“减少动态”设置验证并比较；切换插件开关、卸载并刷新，检查原有界面恢复。可在浏览器开发者工具查看 `document.body.hasAttribute('data-dsh-light-eye-care')`（运行时样式是否挂载）、`document.body.hasAttribute('data-ds-dark-theme')`（活动主题是否为深色），停用后前者应消失；另检查控制台中的插件加载错误。若没有浅色效果，检查插件是否启用、是否被其他主题覆盖、用户是否在启用后选择了其他外观，以及当前 DSH 版本；若局部有暗色残留，请记录具体页面而不要覆盖不稳定的编译类名。此包不使用 localStorage 诊断键，也不改写任何用户配置。

已在 DSH 0.2.2-rc.3 的实际界面验证浅色加载、切换深色再切回、插件关闭与卸载后的覆盖清理，以及启用系统减少动态时取消新增过渡。快捷键搜索框的键盘焦点在当前 DSH 版本中未显示独立焦点环（原生输入框设置了无轮廓）；该限制尚待宿主修复。
