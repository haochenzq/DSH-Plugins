# 深空探索 · Cosmos

基于 DSH Web 公开 `theme` 与 `shell.overlay` 的本地主题，兼容 DSH >=0.2.2-rc.1 <0.3.0。默认「星云航迹」含行星、星云与错峰分布的星点；「深空鲸影」使用本包内绘的原创矢量鲸，不依赖旧主题或网络；「极夜专注」保留低干扰星光。不涉及桌面原生启动页，预览稿的启动画面未实现。

## 使用与设置

安装、启用本插件前应停用其他配色主题，避免 token 叠加；不会删除或修改旧主题。安装方式可用插件管理器安装 `link:<本目录绝对路径>`，开发链接目录不要移动。默认配置 `{}`，明暗模式均使用同一套深色配色，不改变 DSH 原有明暗偏好。

界面右侧靠上 `✦` 按钮打开「深空主题」面板；选择场景和动效（丰富、柔和、静态），立即生效。默认星云航迹 / 柔和。按钮可用键盘操作，展开面板按 Escape 或关闭按钮返回焦点；非控件的全屏视觉层不接收鼠标。场景层压低透明度，尤其中央正文区域，避免干扰阅读。由于按钮占用极小屏幕区域，必要时可关闭面板；请在实际布局中检查它不挡其他控件。

设置仅保存到当前来源的浏览器 `localStorage` 键 `dsh-cosmos-theme.settings`，同源其他标签页会同步；无存储权限时退化为本页会话设置。丰富档在边缘显示低频流星，柔和、静态、极夜及系统减少动态效果时隐藏；系统启用减少动态效果时所有动效强制静止，不覆盖用户存储值；页面隐藏时暂停动画。完全离线、无远程资源、无模型调用。

## 升级、停用和卸载

本次源码升级为 0.2.0。已 link 的部署是否立即生效取决于宿主的客户端插件 bundle 构建和监听状态：如没有 dev:web 监听重建，需由运行该 GUI 的 DSH 重新加载/重启以生成最新 bundle，再刷新当前 Web 页面验证；仅修改源文件不能保证浏览器已载入新代码。不要启动另一个服务器代替现有 GUI 验证。启用后如需恢复原配色，在插件管理器停用本包并启用所需主题；卸载时移除 `dsh-cosmos-theme`。停用/卸载会撤销本插件的 token、样式、slot 和事件监听；为便于再启用，浏览器存储的场景/动效偏好会保留。若需清除偏好，在该 GUI 同源开发者工具执行 `localStorage.removeItem('dsh-cosmos-theme.settings')`；该操作不清除其他插件数据。

## 维护与验证

颜色唯一来源为 `../../themes/dsh-abyss-theme-design/theme.css` 的 `--ds-cosmos-*`；客户端 palette 与之逐项镜像，视觉组件只消费颜色变量。在项目工作区根目录运行 `node --test plugins/dsh-cosmos-theme/test/cosmos.test.cjs` 进行无宿主静态及模拟生命周期验证（测试依赖同一工作区的设计 token，不随发布包提供）；这不能替代真实 GUI 验收。

真实界面检查：

1. 刷新后检查 `document.documentElement.dataset.cosmosApplied === '0.2.0'`、`#dsh-cosmos-theme-style` 唯一、`.cosmos-star` 为 145 个。检查 `.cosmos-sky` 的 `data-scene`、`data-motion`。
2. 点击右侧设置，逐一切换三种场景和三种动效；刷新后选择应保持。用键盘打开、切换、Esc 关闭；确认文本、输入框、其他插件与弹窗仍可操作、画面可读。
3. 模拟 `prefers-reduced-motion: reduce` 确认动效停止；页面隐藏后 `.cosmos-sky[data-hidden=true]` 暂停动画。
4. 停用后检查样式、slot/控件和 token 覆盖消失；重新启用恢复；卸载后检查同样恢复。存储偏好保留属于设计行为，可按上节手动清除。
5. 控制台检查模块或 slot 错误；若版本未更新，确认宿主已重载最新 bundle，再刷新现有 GUI。星空 DOM 存在不代表视觉与交互验收通过。
