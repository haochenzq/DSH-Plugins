# 深空探索 · Cosmos

基于 DSH Web 公开 `theme` 与 `shell.overlay` 的本地主题，兼容 DSH >=0.2.2-rc.1 <0.3.0。默认「星云航迹」含行星、星云与错峰分布的星点；「深空鲸影」使用本包内绘的原创矢量鲸，不依赖旧主题或网络；「极夜专注」保留低干扰星光。不涉及桌面原生启动页，预览稿的启动画面未实现。

## 使用与设置

安装、启用本插件前应停用其他配色主题，避免 token 叠加；不会删除或修改旧主题。安装方式可用插件管理器安装 `link:<本目录绝对路径>`，开发链接目录不要移动。默认配置 `{}`，插件不会改变 DSH 原有明暗偏好。**请在「设置 → 通用设置 → 外观」选择「深色」**：插件虽在浅色模式下也覆盖部分颜色，但未覆盖的宿主颜色仍会使用浅色方案，可能出现白底浅字等对比度问题。需要浅色外观时请先停用本插件。

左侧栏底部、OpenAI 用量入口上方的 `✦` 按钮打开「深空主题」面板（面板向上展开）；窄屏下按钮退到左上角、面板向下展开。选择场景和动效（丰富、柔和、静态），立即生效。默认星云航迹 / 柔和。丰富档明显强于柔和：星点以约一半周期大幅明暗与缩放闪烁、星云与行星/鲸影加速呼吸浮动、三颗错峰流星；柔和档接近系统减少动态效果，静态档完全静止。按钮可用键盘操作，展开面板按 Escape 或关闭按钮返回焦点；非控件的全屏视觉层不接收鼠标。场景层压低透明度，尤其中央正文区域，避免干扰阅读。按钮只占侧栏空白处，不压聊天内容；请在实际布局中检查它不挡其他控件。

设置仅保存到当前来源的浏览器 `localStorage` 键 `dsh-cosmos-theme.settings`，同源其他标签页会同步；无存储权限时退化为本页会话设置。流星仅在丰富档显示；「极夜专注」下流星隐藏、星点保持静止且星云较淡，丰富/柔和档仍会改变星云速度，静态档停止动画。系统启用减少动态效果时所有动效强制静止，不覆盖用户存储值；页面隐藏时暂停动画。完全离线、无远程资源、无模型调用。

## 升级、停用和卸载

当前源码版本为 0.3.5：修复「极夜专注＋丰富」时星点意外闪烁和星云过亮的问题，并修正客户端版本诊断。0.3.4 将主题按钮上移到 `bottom:138px` 以避让余额入口；0.3.1 加强「丰富」动效。已 link 的部署是否立即生效取决于宿主的客户端插件 bundle 构建和监听状态：如没有 dev:web 监听重建，需由运行该 GUI 的 DSH 重新加载/重启以生成最新 bundle，再刷新当前 Web 页面验证；仅修改源文件不能保证浏览器已载入新代码。不要启动另一个服务器代替现有 GUI 验证。启用后如需恢复原配色，在插件管理器停用本包并启用所需主题；卸载时移除 `dsh-cosmos-theme`。停用/卸载会撤销本插件的 token、样式、slot 和事件监听；为便于再启用，浏览器存储的场景/动效偏好会保留。若需清除偏好，在该 GUI 同源开发者工具执行 `localStorage.removeItem('dsh-cosmos-theme.settings')`；该操作不清除其他插件数据。

## 维护与验证

2026-11-19：0.3.5 的 3 项自动测试通过；在现有 GUI 刷新后核实诊断标识为 0.3.5，极夜三档保持星点静止、云较淡，其他场景丰富档仍运动，减少动态效果时动画停止。控件与余额入口间距约 22px，控制台无错误；未改用户偏好或 profile。

颜色唯一来源为 `../../themes/dsh-abyss-theme-design/theme.css` 的 `--ds-cosmos-*`；客户端 palette 与之逐项镜像，视觉组件只消费颜色变量。在项目工作区根目录运行 `node --test plugins/dsh-cosmos-theme/test/cosmos.test.cjs` 进行无宿主静态及模拟生命周期验证（测试依赖同一工作区的设计 token，不随发布包提供）；这不能替代真实 GUI 验收。

真实界面检查：

1. 重新加载插件并刷新后检查 `document.documentElement.dataset.cosmosApplied === '0.3.5'`、`#dsh-cosmos-theme-style` 唯一、`.cosmos-star` 为 145 个、`.cosmos-meteor` 为 3 个。检查 `.cosmos-sky` 的 `data-scene`、`data-motion`。
2. 点击左侧栏底部（OpenAI 用量入口上方）的按钮，逐一切换三种场景和三种动效；刷新后选择应保持。确认按钮位于侧栏底部、不遮聊天内容、面板向上展开；用键盘打开、切换、Esc 关闭；确认文本、输入框、其他插件与弹窗仍可操作、画面可读。
3. 模拟 `prefers-reduced-motion: reduce` 确认动效停止；页面隐藏后 `.cosmos-sky[data-hidden=true]` 暂停动画。
4. 停用后检查样式、slot/控件和 token 覆盖消失；重新启用恢复；卸载后检查同样恢复。存储偏好保留属于设计行为，可按上节手动清除。
5. 控制台检查模块或 slot 错误；若版本未更新，确认宿主已重载最新 bundle，再刷新现有 GUI。星空 DOM 存在不代表视觉与交互验收通过。
